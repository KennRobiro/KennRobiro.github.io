Web vulnerabilities are common entry points for attackers. In this post, we will explore **sql-injection** and **XSS** -- two of the OWASP top 10.

## SQL Injection
This occurs when unsanitized input is used in database queries.

## XSS
Cross-Site Script allows attackers to inject scripts into web pages viewed by others.
